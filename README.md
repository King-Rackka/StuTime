Nama Website : StuTime

Nama Tim : Timnya Bebas
 
Dengan Backend : TIDAK
 
| Fitur | Deskripsi |
| --- | --- |
| **Dashboard** | Sistem menyusun prioritas tugas berdasarkan deadline, tingkat kesulitan, dan estimasi waktu secara otomatis. |
| **Task** | Menggunakan prinsip *Eisenhower Matrix* yang dibantu AI untuk menentukan urgensi, lengkap dengan rangkuman materi. |
| **Noto** | Optimasi penyimpanan browser lokal memastikan perubahan data terupdate seketika tanpa *loading* server. |
| **Foctime** | Data Anda adalah milik Anda. Semua disimpan di dalam browser (IndexedDB) untuk keamanan privasi maksimal. |
| **Calendar** | Antarmuka minimal klik, maksimal informasi. Lihat semua yang Anda butuhkan dalam satu layar cerdas. |
