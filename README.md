**Nama Website** : StuTime

**Nama Tim** : Timnya Bebas
 
**Dengan Backend** : TIDAK

**Daftar Fitur Utama** :
 
| Fitur | Deskripsi |
| --- | --- |
| **Dashboard** | Overview harian yang menampilkan jadwal, tugas selesai, sesi fokus, dan menit belajar dalam satu tampilan ringkas. |
| **Task** | Kelola jadwal harian dengan fitur pin, done, dan detail tugas lengkap dengan shortcut pencarian tutorial di YouTube dan Google. |
| **Noto** | Noto merupakan gabungan dari Notes dan Tools, **Notes** sebagai fitur untuk tempat menyimpan catatan belajar serta tools **Journal Formatter** untuk membuat atau memberikan format pada sumber pencarian seperti jurnal, buku, atau website |
| **Foctime** | Timer fokus mengerjakan tugas dengan ada mode break yang bisa dikustom |
| **Calendar** | Visualisasi jadwal dalam tampilan kalender bulanan untuk melihat sebaran tugas dan deadline secara menyeluruh. |
